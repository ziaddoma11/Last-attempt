## مصدر البيانات
- السعر: `https://biquote.io/api/XAUUSD` (يُستخدم `mid` و`dayDiffPercent`).
- الشموع: `https://biquote.io/api/XAUUSD/ohlc?interval=5m|15m&limit=180`.
- لم يمكن فحص شكل الاستجابة الحية أثناء الإنشاء، لذلك المحلل يقبل أسماء حقول شائعة (`t/time` و`o/open`… أو مصفوفات) ويُظهر خطأً واضحاً إذا لم يتعرف على الشكل. **لا تُعرض أي أسعار وهمية أبداً.**
- إن منع المصدر الطلبات من المتصفح (CORS) أو توقف، تظهر رسالة خطأ. بدائل مجانية: Twelve Data أو Alpha Vantage (تتطلب مفتاحاً؛ لا تضعه في كود المتصفح، استخدم وسيطاً مثل Cloudflare Worker).
- السعر قد يختلف عن سعر OW Markets (السبريد، المزود، التأخير).

## منطق الإشارة
ثلاثة أوضاع من القائمة في الصفحة: **SMC** (الافتراضي) أو SMC ثم الكلاسيكي أو الكلاسيكي (10 استراتيجيات).
### SMC
- **الهيكل:** قمم/قيعان (Fractal 3)، HH/HL أو LH/LL، وBOS/CHoCH عند إغلاق شمعة خلف آخر قمة/قاع.
- **السيولة:** BSL فوق القمم وSSL تحت القيعان، وسحب السيولة = اختراق بالذيل ثم إغلاق داخل المستوى.
- **FVG/iFVG:** فجوات الشموع الثلاث، وتنقلب إلى iFVG إذا أُغلقت شمعة عبرها.
- **OB:** آخر شمعة معاكسة قبل الاندفاع الذي كسر الهيكل، وتُلغى إذا أُغلق السعر خلفها.
- **الدخول:** (OB + FVG/CISD) أو (فيبو 0.5–0.786 + CISD) مع شمعة تأكيد، ونقاط توافق ≥ 4 من 7.
- **الوقف:** خلف منطقة الدخول/القاع المرجعي/ذيل سحب السيولة. **الأهداف:** TP1 = امتداد 1.272، TP2 = أقرب سيولة DOL أو امتداد 1.414.
- **SMT:** مقارنة الذهب بتوأمه الفضة XAGUSD (ناسداك/إس آند بي لا يرتبطان بالذهب). إن لم يتوفر الرمز يظهر «غير متاح» ولا يؤثر.
لا يوجد ضمان لنسبة نجاح؛ راجع الاختبار الرجعي وسجل الإشارات.
